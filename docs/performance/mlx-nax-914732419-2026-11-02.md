# MLX 914732419 (0.32.5) NAX verify kernels on M5 — 2026-11-02

Upstream MLX `914732419` (reports 0.32.5; not yet on PyPI) adds NAX
quantized GEMV for 6-16 rows (`affine_qmv_nax`), split-K / staged
`fp_qmm_t_nax`, and NAX `sdpa_split` for 2-8 query rows. AX now uses them for
speculative verify on **M5 or later** (generation >= 5, macOS 26.2+) when the
linked MLX is 0.32.5 or newer. `mlx.version` stays on the published 0.32.4
wheel, where every path below is inert; they turn on with a 0.32.5+ runtime.
All numbers: MacBook Pro M5 Max 128 GB, macOS 26.x, greedy.

## Stock MLX (no AX change)

Stock `quantized_matmul` at Qwen 3.8 27B shapes, five formats, geomean
speed of 914732419 over 0.32.4:

| rows | 1-4 | 6 | 8 | 12 | 16 | 24 | 32 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| speed | 1.01-1.03 | 1.70 | 2.08 | 3.05 | 2.01 | 1.46 | 1.36 |

At 1-4 rows 914732419 matches the published 0.32.4 wheel and a 0.32.4 build
made with the same flags (time ratio 0.97-0.99). An earlier pairing against
one other 0.32.4 source build read as a 3-7% slowdown there; that build was
itself 5% faster than the wheel, and a matched rebuild did not reproduce it,
so there is no upstream 1-row regression to chase. MXFP4 / MXFP8 248K
vocabulary heads at 6-16 rows are 0.62-0.71x. End to end with no AX change:
prefill on short prompts 1.38-1.47x (27B), decode flat (within run noise).

## What AX changes (M5+, MLX >= 0.32.5)

| path | change | knob |
| --- | --- | --- |
| verify QMM | 6-8 row verify projections use stock NAX QMM instead of AX's verify kernels; fp-mode heads >= 100K wide and affine 8-bit stay on AX's kernels; 2-5 rows unchanged | `AX_MLX_MTP_VERIFY_QMM_NAX_STOCK_MIN_ROWS` (default 6, `0` off); `AX_MLX_MTP_VERIFY_QMM_NAX_PAD=1` pads 3-5 rows to 6 (opt-in: loses on prose) |
| verify attention | relaxed target verify (DFlash2, relaxed MTP) hands the whole 2-8 row window to native SDPA (NAX `sdpa_split`) instead of per-row singleton SDPA / f32 upcast; exact profiles keep the fold | `AX_MLX_NAX_VERIFY_NATIVE_SDPA` (default on; numerics token `nax_verify_sdpa=0`) |
| DFlash2 window | round cost `39.2 + 0.95 * (w - 4)` ms instead of `40 + 5.07 * (w - 4)` (measured 39.2 / 42.1 / 43.0 ms at 4 / 6 / 8 rows) | — |
| Flash Next tiled QSA scores (opt-in) | admitted on 0.32.5 (bit-match tests pass on applegpu_g17s) | `AX_MLX_FLASH_NEXT_QSA_TILED_SCORES` |

## End to end (MLX 914732419 build, vs the same binary with the hand-offs off)

Qwen 3.8 27B MXFP4 + DFlash2, 17-prompt real suite, 256 tokens, median of 2:

| arm | mean | median | min | max |
| --- | ---: | ---: | ---: | ---: |
| shipped (QMM + SDPA hand-off, NAX window cost) | **1.250** | **1.309** | 0.967 | 1.418 |
| QMM + SDPA hand-off, classic window cost | 1.176 | 1.222 | 1.003 | 1.312 |
| QMM hand-off only | 1.124 | 1.172 | 0.852 | 1.263 |
| SDPA hand-off only | 1.011 | 1.010 | 0.975 | 1.049 |

Code prompts 1.31-1.42x (139 -> 183 tok/s), prose 0.97-1.41x. Long context
(9k tokens): 1.25-1.34x, mostly from the SDPA hand-off. Qwen 3.6 35B-A3B
DFlash2 1.001x (routed experts use gather QMM; most prompts hand off to MTP;
with hand-off to MTP disabled, the NAX hand-offs are 1.00x at 4 and 8 rows),
Qwen 3.6 27B MTP depth 3 1.003x (4-row verify). Greedy output is not
token-identical to the hand-offs-off arm (9/17 identical): relaxed verify.

The DFlash2 window cost was fitted on 27B MXFP4, M5 Max, MLX 914732419,
windows of 4-8 rows. Refit it when any of those changes (a new MLX release,
another M5 or M6 SoC, a new default target). On 35B-A3B (hand-off to MTP
disabled, 7 prompts) rounds cost 17.2 / 19.9 / 21.6 ms at 4 / 6 / 8 rows, a
steeper curve, but the adaptive policy with the same cost is still the best
arm: 1.14x pinned 4, 1.05x pinned 6, 1.04x pinned 8 with the hand-offs off.

`ax-engine-bench doctor --json` reports `nax_verify_kernels` (host, MLX
version, metallib probes, which hand-offs are active) on NAX hosts, with one
advice row naming the missing condition when the hand-offs are off. Each
hand-off needs a positive probe of its own kernels in the linked
`mlx.metallib` (`qmv_nax` for QMM, `sdpa_split_reduce` for SDPA); a metallib
that cannot be found or read keeps AX's own kernels. `/metrics` splits
speculative tokens by `draft_source`
(`ax_engine_speculative_{draft,accepted}_tokens_total`), so DFlash2 and the
MTP head can be told apart after a hand-off.

Measured and not adopted: deeper MTP (depth 5: 0.91x, depth 7: 0.75x mean),
larger prefill chunks for Flash Next (1024: -6% at 9k, +8% at 39k), padding
3-5 row verifies (ties on code, -3..-6% on prose). CPU SME at verify shapes
is 4-250x slower than the GPU. The Neural Engine through Core ML (fp16 1x1
convolution, the ANE layout) reaches 4-11 TFLOPS at 27B projection shapes
with 128-2048 tokens, against 50-62 TFLOPS for MLX on the GPU, so it is not
a prefill path on M5 Max.

## Build recipe (source build of 914732419)

`scripts/build-mlx-source.sh` builds this commit with deployment target 26.2
and checks that the result carries the NAX kernels. It prints the
`MLX_LIB_DIR` / `MLX_INCLUDE_DIR` / `AX_MLX_VERSION_OVERRIDE=1` settings to
build AX against it. See
[Running an unreleased MLX locally](../MLX-BACKEND.md#running-an-unreleased-mlx-locally).
The deployment target must be 26.2 or later: below it the NAX kernels are
compiled out, and the runtime gate then keeps AX's own kernels.

## Activation checklist (moving `mlx.version` to 0.32.5)

The merged code is inert on 0.32.4, so the pin bump is the real activation.
Before merging it:

1. Install the released 0.32.5 wheel (not a source build) and confirm
   `mx.__file__` points at it. `python -I` ignores `PYTHONPATH` and silently
   loads the installed MLX.
2. `ax-engine-bench doctor --json` on an M5 host: `active` and
   `native_sdpa_active` true, both metallib probes true.
3. Re-run the 27B DFlash2 suite against the hand-offs-off arm. Report mean,
   median and minimum speed, acceptance and generated-token counts, and how
   many prompts stay token-identical. The released wheel must match this
   record within run noise.
4. On an M3/M4 host, doctor reports no `nax_verify_kernels` and decode speed
   is unchanged.
5. Roll back without a rebuild: `AX_MLX_MTP_VERIFY_QMM_NAX_STOCK_MIN_ROWS=0`
   and `AX_MLX_NAX_VERIFY_NATIVE_SDPA=0`.
