# Whisper tokenizer asset

`multilingual.tiktoken` is the canonical vocabulary distributed by
[OpenAI Whisper](https://github.com/openai/whisper) and
[MLX Whisper](https://github.com/ml-explore/mlx-examples/tree/main/whisper).
It is included under the upstream MIT license so native MLX checkpoints—which
do not duplicate tokenizer files—load offline and without modification.
